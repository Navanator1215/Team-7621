## Project Description
Driscoll's R&D Platform is a Flask-based web application for managing agricultural field trials. Users can create, view, edit, delete, search, and filter trial records. The app also supports media uploads so users can attach images to trials.

## Abstract
This project simulates an R&D trial management platform for agricultural research teams. The goal is to organize field trial information such as crop, variety, location, objective, season, status, notes, and media. The application uses a Flask frontend, Flask backend API, and a database to store and manage trial data.

# How to Run the Program

## Install Requirements

Before running the program, install the required Python packages:

```bash
pip install -r requirements.txt
```

## 1. Start the backend

With your Python virtual environment running:

```bash
cd backend
python main.py
```

## 2. Start the frontend

Open a second terminal with your Python virtual environment running:

```bash
cd frontend/src
flask --app app.py --debug run
```

## 3. Open the application

Go to:

```txt
http://127.0.0.1:5000
```
